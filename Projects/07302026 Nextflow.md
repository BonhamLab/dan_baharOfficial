### Nextflow

Nextflow is a workflow manager that runs all of the commands for you and keeps track of them. You can construct the pipeline once the steps and the order they run in, then Nextflow runs the whole chain itself. It also remembers what already finished, so if a step fails partway, you can pick up where it left off instead of starting over.

For example, we previously had to run Waafle by hand, one at a time. Nextflow will be able to run Waafle automatically, infinite times, without the need for human intervention.
